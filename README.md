# uf2216-aulanexo-Martinez_Salmeron_Maria_Angeles

## Objetivo respositorio
En este repositorio vamos a gestionar la documentación de una empresa llamada Aula Nexo Formación S.L. que se dedica a impartir cursos de informática, ofimática y gestión empresarial en modalidad presencial y online.

##Contenido respositorio
Este respositorio está estructurado en cuatro categorías (Administracióh, Docente, Alumnos y Página Web) y cada categoría a su vez está compuesta por dos subcarpetas (Gastos academia, funcionamieno interno, teoría, práctica, material alumnos, privado, publicaciones y documentación cursos, además dentro de algunas subcarpetas también hemos creado una carpeta (proveedoresm bases de datos,temario y ficha de curso).

## Localización documentos
Para localizar dichos documentos tendríamos que ir a la carpeta correcta, para el caso de la programación y de los exámenes nos dirigiremos a la carpeta de docentes y dentro de ésta a la carpeta de material de alumnos. Para localizar una factura tendríamos que ir a la carpeta de administración y dirigirnos a la carpeta de gastos de academia.

## Tipo de búsquedas
La búsqueda facetada consiste en introducir varios filtros para encontrar el documento de manera mucho más rápida, cuántos más filtros la búsqueda será más exacta.Ej: cuando cumpramos ropa en una página web, queremos camiseta de manga corta, de color rojo y talla mediana.
La búsqueda full-text consiste en hacer una búsqueda dentro del contenido del documento. Ej: abrimos un documento pdf y en el buscador del mismo documento introducimos el término o leemos todo el documento para encontrar aquello que buscamos.
# Arquitectura
La arquitectura ideal a implementar en este repositorio sería una arquitectura híbrida, combinando la implementación de una Base de datos, para guardar los metadatos que apuntan hacia el fichero, y la implementación de ficheros.
